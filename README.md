# Brick_Breaker_Game
This game is developed using C++ OpenGL.

# Run
```
g++ main.cpp level1.cpp level2.cpp level3.cpp level4.cpp level5.cpp level6.cpp level6.cpp -o main -lGL -lGLU -lglut
Or
g++ main.cpp level1.cpp level2.cpp level3.cpp level4.cpp level5.cpp level6.cpp -o main.exe -lfreeglut -lopengl32 -lglu32
```
```
./main
```
